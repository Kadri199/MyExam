دليل تشغيل موقع اختبار الرياضيات

محتويات المشروع:
- index.html: واجهة التلميذ.
- admin.html: لوحة الأستاذ.
- student.js / admin.js: منطق الاختبار والإدارة.
- firebase-config.js: إعداد الاتصال بقاعدة البيانات.
- firestore.rules و storage.rules: قواعد حماية البيانات والصور.

أولاً: إنشاء قاعدة Firebase (مجاني ضمن حدود الخطة المجانية)
1) افتح https://console.firebase.google.com وأنشئ مشروعاً جديداً.
2) أضف تطبيق Web (أيقونة </>) وانسخ إعدادات Firebase إلى firebase-config.js.
3) من Authentication > Sign-in method فعّل:
   - Anonymous للتلاميذ.
   - Email/Password للأستاذ.
4) من Authentication > Users أنشئ حساب الأستاذ ببريده وكلمة مروره.
5) من Firestore Database أنشئ قاعدة بيانات.
6) من Storage فعّل مساحة تخزين الصور.
7) انسخ محتوى firestore.rules إلى تبويب Rules في Firestore ثم Publish.
8) انسخ محتوى storage.rules إلى تبويب Rules في Storage ثم Publish.

ثانياً: تشغيل الموقع محلياً
لا تفتح index.html بالنقر المزدوج لأن المتصفح قد يمنع وحدات JavaScript.
يمكنك استخدام VS Code مع إضافة Live Server، ثم فتح index.html عبر Live Server.
يجب أن يكون ملف firebase-config.js مضبوطاً أولاً.

ثالثاً: نشر الموقع على الإنترنت
يمكن نشر ملفات المجلد على Firebase Hosting:
- ثبّت Node.js ثم Firebase CLI: npm install -g firebase-tools
- سجّل الدخول: firebase login
- داخل مجلد المشروع: firebase init hosting
- اختر مجلد النشر الحالي (أو public بعد نسخ الملفات إليه)، واجعل index.html صفحة البداية.
- انشر: firebase deploy

ملاحظات مهمة:
- لوحة الأستاذ متاحة عبر /admin.html.
- الأسئلة الافتراضية أمثلة؛ عدّلها من لوحة الأستاذ ثم اضغط حفظ الأسئلة.
- العلامة المعروضة /16 تخص الأسئلة الاختيارية الستة عشر فقط.
- الأسئلة الأربعة المصورة تحفظ صورها للمراجعة اليدوية، ولا تدخل في علامة /16.
- يجب أن تكون الأسئلة 16 اختياراً بثلاثة خيارات، والأسئلة المصورة الأربعة.
- هذه نسخة أولية تعليمية. في الاختبارات عالية الأهمية ينبغي نقل التصحيح إلى جهة الخادم لمنع التلاعب بعلامة الإرسال، وإضافة ضوابط أقوى لمنع تكرار المشاركات.
- لا تشارك كلمة مرور حساب الأستاذ مع التلاميذ.
